# CrucibleAI-The-Condescending-Local-AI-Tutor
CrucibleAI is a privacy-first, locally hosted intelligent tutoring application designed to teach complex topics through sarcastic, tough-love pedagogy. Powered by local large language model gemma4:26b via Ollama, CrucibleAI combines multi-modal document ingestion, context-aware conversational memory, and a custom persona engine.
